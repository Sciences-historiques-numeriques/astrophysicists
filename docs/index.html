What is a triplestore?

A triplestore is a database for linked data. Instead of tables it stores statements called triples: a subject, a predicate and an object, for example a person – was born in – a city. Every entity, class and property is identified by a URI, and the statements can be grouped into named graphs, for example one graph per dataset or source. The data is queried with SPARQL through a SPARQL endpoint.

What this site does

This is a read-only browser: it sends SPARQL queries to the triplestore and displays the results. Nothing is changed on the server.

  • Classes: the types of things in the data, with the number of instances per graph.
  • Properties: the relations between classes, with the domain and range as used in the data.
  • Instances: all entities of a class, paginated and searchable.
  • Entity cards: one page per entity with its outgoing and incoming relations; every link leads to the next entity.
  • Graphs: the list at the top of each page chooses which named graphs are queried, and follows you from page to page.
  • Labels, filters and sorting: rdfs:label is shown where available, and tables can be filtered and sorted.
